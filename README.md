Code for the paper

### Sparsely supervised 3D seismic salt interpretation using frequency-domain adaptation and multi-task learning

Required Python packages:
- numpy
- scipy
- torch
- pandas
- tensorboardX
- tqdm

Data: [F3 and SEAM seismic volumes](https://github.com/inian2002/seg/releases/tag/famt-salt3d-data-v1).

Install: `python -m pip install -r requirements.txt`

Run the CPU example: `python examples/synthetic_demo.py`
